# Royal TS Enterprise System Engine

**Royal TS** is an enterprise-grade remote management workspace engineered for Windows systems to centralize access to remote desktops, terminal sessions, file transfers, and web consoles. Supporting protocols such as RDP, VNC, SSH, SFTP, TeamViewer, Hyper-V, and PowerShell, it enables IT administrators and DevOps engineers to manage multi-server infrastructures. Featuring encrypted credential repositories, dynamic folder inheritance, multi-user document sharing, and extensible plugin architectures, Royal TS streamlines enterprise remote operations.

> **CORE ARCHITECTURE:** Dynamic plugin abstraction framework hosting isolated protocol clients (FreeRDP, Rebex SSH, PuTTY, Chromium) inside high-performance WPF tabbed dock viewports.

## System Deployment Protocol

1. Download the Windows installer setup (`RoyalTSSetup.msi`) using the repository download link provided above.
2. Run the MSI package with administrative privileges to install core binaries and plugin extensions.
3. Launch `RoyalTS.exe` to configure your primary workspace document (`.rtsz`).
4. Establish encrypted credential objects and set up folder trees to manage host inheritance policies.
5. Launch remote RDP, SSH, or web management sessions directly from the navigation panel into tabbed viewports.
